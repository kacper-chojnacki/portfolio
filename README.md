# kacperchojnacki.pl

Personal portfolio of Kacper Chojnacki — Software Engineer at Dynatrace, MSc Computer Science student at JKU Linz.

**Live:** [kacperchojnacki.pl](https://kacperchojnacki.pl)

## Tech stack

- [Astro](https://astro.build) — static site generator
- [Tailwind CSS v4](https://tailwindcss.com) — styling
- GitHub Pages — hosting via custom domain

## Development

```sh
npm install
npm run dev      # localhost:4321
npm run build    # production build → ./dist
npm run preview  # preview production build locally
```

## Deploy

Push to `main` — GitHub Actions automatically builds and deploys to GitHub Pages.
